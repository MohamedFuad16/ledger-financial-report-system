# Project state

> Last updated: 2026-08-21

## Current state summary

The React/Flask workspace now includes an evidence-backed Bakuraku seed list, a Firecrawl-driven FY2020–FY2025 Annual Report corpus builder, direct normalized PDF storage, health screening, an atomic SHA-256 manifest, and a standalone background worker. Uploads and runs retain company/year/timestamp namespaces, while each corpus company/year has one canonical PDF; a successful recrawl atomically replaces it and a failed replacement leaves the verified prior file intact. Both active strategies can switch between upload input and a searchable single/batch corpus picker; selected SHA-256 manifest entries are path-validated and staged by durable reference, so source PDFs are never duplicated and output locations/counts remain visible in Report corpus. Users can delete one downloaded PDF through a branded, keyboard-dismissable confirmation dialog: server-side deletion resolves only a manifest SHA-256 entry, constrains it to corpus storage, prunes empty download folders, and preserves prior extraction runs. Runtime saves verify the saved or replacement Firecrawl key through the read-only credit-usage endpoint before persistence. Live Firecrawl smoke tests retrieved and screened the official 3M FY2022 10-K and AppBank FY2024 securities filing; AppBank is stored canonically at `corpus_dataset/AppBank/2024/AppBank_annual_report_2024.pdf`, all 105 pages are readable, its FY2024/balance-sheet/JPY evidence is recorded, and it appears as Ready in the Strategy 2 corpus picker. Japanese report screening recognizes balance-sheet, fiscal-year and currency terms while preserving the current extractor's M-USD contract boundary. Extraction jobs are snapshotted under `runs/_extraction_jobs`, rehydrated by the client after route changes or refreshes, and continue on the backend independently of the visible route. Strategy 2 live and historical comparisons use a matched report cohort: a report contributes only when every selected parser succeeds, each report is equally weighted, and reruns do not silently overweight a document. The UI maps the user's Resume/editor design system into Ledger with matched light/dark palettes, a persistent collapsible rail, locale-derived English/Japanese copy, and a persistent manual switcher. Canonical output rows, definitions, inline result sheets, and CSV exports localize with the selected language while English keys remain stable in stored artifacts. Execution streams show one current company, up to six fiscal-year chips, and one active report card that advances through parser/stage events; this avoids a multi-company wall while retaining comparison progress. The stored-report picker is similarly flattened to avoid nested panels. All pipeline typography stays neutral ink while state color is confined to indicators and borders. Parser choices use roomy, neutral capsule typography and mobile navigation gives New extraction a single full-width Strategy 2 touch target without the desktop shortcut key. The retired static client, 643 MB of unreferenced upload duplicates, one obsolete run, and superseded/incorrect corpus files were removed; React/Vite is now the sole UI source. The workspace is a public GitHub repository, the React production UI is public on Vercel, and a Tokyo `t3.medium` EC2 instance serves the Flask API through Caddy/Let's Encrypt. Production files live on its encrypted 40 GiB gp3 EBS volume rather than browser storage, so they survive refreshes and service restarts; the single root volume is not a cross-instance backup and is deleted with the instance. The assignment API no longer uses a deployment access token; CORS is limited to production aliases, while all provider and connector credentials remain backend-only. SSH is closed and IMDSv2 is required. Private per-session visit telemetry is stored in a bounded Upstash log and emailed to the verified owner through a styled HTML table via SES; all connector values stay in SSM and the EC2 environment. The README uses the generated Ledger mark, the code-backed runtime report lives in `docs/CURRENT_STATUS.md`, and its rendered English PDF has been delivered through SES.

Corpus jobs now share a process-wide seven-second Firecrawl request gate and account-wide Retry-After cooldown, snapshot their state under `runs/_corpus_jobs`, and rehydrate after navigation/reload. Dashboard conclusions use display-rounded co-leaders instead of silently breaking 40.8% ties. The FY2021 3M incident is audited as a broken embedded font/text layer: only Total Assets matches (`1/27 = 3.7%`) across all text-only passes, while rendered printed page 47 is visually correct. FY2022 is the only complete assignment-supplied answer key; other year keys remain internally reconciled but provisional pending a PDF-hash-pinned, page-cited dual-entry audit.
