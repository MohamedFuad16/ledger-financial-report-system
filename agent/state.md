# Project state

> Last updated: 2026-08-21

## Current state summary

The React/Flask workspace now implements two explicit four-parser experiment arms. Strategy 1 runs PyPDF, PyMuPDF4LLM, pdf-inspector and Docling with OCR disabled; Strategy 2 runs the same selectable parsers with OCR enabled, forcing OCR for PyPDF and Docling, using integrated adaptive recovery for PyMuPDF4LLM, and using pdf-inspector per-page classification with native Rust extraction for text pages and exact 200-DPI GLM-OCR/VLM extraction for OCR-needed pages. Per-page OCR provenance is stored. Only the assignment-supplied 3M FY2022 key is authoritative by default; other reports receive Firecrawl candidate rows and require SHA-bound human approval in the Corpus UI before they contribute exact accuracy. Unverified reports remain executable with a warning and can contribute speed/coverage.

The corpus builder performs two paced Firecrawl phases: official report discovery, then a structured 27-row candidate extraction after the PDF has been directly downloaded, screened and canonically stored. A cross-process manifest lock protects canonical PDF/upsert/approval/delete operations, and the cross-process Firecrawl gate defaults to 12.5 seconds while honoring Retry-After. One canonical PDF is retained per company/year; successful recrawls replace it atomically, while failed replacements preserve the prior file. Corpus and extraction job snapshots persist under `runs/_corpus_jobs` and `runs/_extraction_jobs`, and the React client rehydrates them after navigation or refresh.

Both strategies support upload or searchable single/batch corpus selection. The UI provides source-PDF review, editable candidate answers, Save & Approve, SHA-scoped deletion confirmation, bilingual display, matched light/dark themes, a responsive collapsible rail, one live execution card per report, and matched-cohort parser summaries. The workspace is a public GitHub repository; Vercel serves React and a Tokyo `t3.medium` EC2 instance serves Flask through Caddy. Persistent PDFs/manifests/runs live on its encrypted EBS volume. The public assignment API has no browser access token; all provider, Firecrawl, Upstash and SES credentials remain backend-only.

Dashboard conclusions use display-rounded co-leaders rather than silently breaking visible ties. The former FY2021 `3.7%` result is retained only as historical evidence of a broken embedded text layer; FY2021 now has no exact-accuracy score until its PDF-hash-bound table is human approved.
