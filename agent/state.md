# Project state

> Last updated: 2026-08-21

## Current state summary

The React/Flask workspace now includes an evidence-backed Bakuraku seed list, a Firecrawl-driven FY2020–FY2025 Annual Report corpus builder, direct normalized PDF storage, health screening, an atomic SHA-256 manifest, a standalone background worker, and company/year/timestamp namespaces for corpus files, uploads, and runs. Both active strategies can switch between upload input and a searchable single/batch corpus picker; selected SHA-256 manifest entries are path-validated and staged by durable reference, so source PDFs are never duplicated and output locations/counts remain visible in Report corpus. Users can delete one downloaded PDF through a branded, keyboard-dismissable confirmation dialog: server-side deletion resolves only a manifest SHA-256 entry, constrains it to corpus storage, prunes empty download folders, and preserves prior extraction runs. Runtime saves verify the saved or replacement Firecrawl key through the read-only credit-usage endpoint before persistence. A live production Firecrawl smoke test retrieved the official 3M FY2022 10-K, saved it as `corpus_dataset/3M/2022/20260821T020528Z/3M_annual_report_2022.pdf`, screened all 252 pages as readable, and staged the SHA-matched document through the production selector contract without a browser access token. The UI maps the user's Resume/editor design system into Ledger with matched light/dark palettes, a persistent collapsible rail, locale-derived English/Japanese copy, and a persistent manual switcher. Canonical output rows, definitions, inline result sheets, and CSV exports localize with the selected language while English keys remain stable in stored artifacts. Execution streams render each real stage as its own BeautifulUI-derived neutral capsule with live timing, completion, and failure state; all pipeline typography stays neutral ink while state color is confined to indicators and borders. Parser choices use roomy, neutral capsule typography and mobile navigation gives New extraction a single full-width Strategy 2 touch target without the desktop shortcut key. The retired static client, 643 MB of unreferenced upload duplicates, one obsolete run, and a superseded corpus file were recoverably removed; React/Vite is now the sole UI source. The workspace is a public GitHub repository, the React production UI is public on Vercel, and a Tokyo `t3.medium` EC2 instance serves the Flask API through Caddy/Let's Encrypt. The assignment API no longer uses a deployment access token; CORS is limited to production aliases, while all provider and connector credentials remain backend-only. SSH is closed, IMDSv2 is required, and the 40 GiB gp3 root volume is encrypted. Private per-session visit telemetry is stored in a bounded Upstash log and emailed to the verified owner through a styled HTML table via SES; all connector values stay in SSM and the EC2 environment. The README uses the generated Ledger mark and a detailed code-backed runtime report lives in `docs/CURRENT_STATUS.md`.
