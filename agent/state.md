# Project state

> Last updated: 2026-08-21 · HEAD: `main`

## Current state summary

The React/Flask workspace now includes an evidence-backed Bakuraku seed list, a Firecrawl-driven FY2020–FY2025 Annual Report corpus builder, direct normalized PDF storage, health screening, an atomic SHA-256 manifest, a standalone background worker, and company/year/timestamp namespaces for corpus files, uploads, and runs. Both active strategies can switch between upload input and a searchable single/batch corpus picker; selected SHA-256 manifest entries are path-validated and staged by durable reference, so source PDFs are never duplicated and output locations/counts remain visible in Report corpus. Adaptive concurrency is a single Settings control shared by every strategy; HTTP 429 feedback shrinks, pauses and gradually recovers the gate. Runtime saves verify the saved or replacement Firecrawl key through the read-only credit-usage endpoint before persistence. The UI maps the user's Resume/editor design system into Ledger with matched light/dark palettes, a persistent collapsible rail, locale-derived English/Japanese copy, and a persistent manual switcher. Canonical output rows, definitions, inline result sheets, and CSV exports localize with the selected language while English keys remain stable in stored artifacts. Execution streams render each real stage as its own BeautifulUI-derived neutral capsule with live timing, completion, and failure state; parser charts use distinct colors and connected series, and the quadrant exposes a 50% target split without overlapping its legend. The public Settings page omits deployment-token controls while retaining masked, editable, test-before-save provider and Firecrawl credentials. History supports explicit select/delete controls, run names display canonically, and row-local result sheets retain the four requested assignment columns. Strategy pages keep a closed-by-default full-width prompt above equal-height input/execution cards, expose model-native reasoning on/off, and leave temperature at its 0.1 Settings default. A failed JSON/Pydantic contract gets one bounded context-preserving repair call, with separate artifacts, and prompt confidence guidance matches the 0.80 gate. Route changes reset every page scroll container to the top. The workspace is a public GitHub repository, the React production UI is public on Vercel, and a Tokyo `t3.medium` EC2 instance serves the protected Flask API through Caddy/Let's Encrypt. Mutations require a Parameter Store-backed token outside the public UI; read APIs remain public, CORS is limited to the production aliases, SSH is closed, IMDSv2 is required, and the 40 GiB gp3 root volume is encrypted. Python contract checks, Vitest, TypeScript/Vite build, corpus staging, localized rendering, TLS, CORS, auth, and in-app browser QA pass.
