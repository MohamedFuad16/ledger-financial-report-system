# Project state

> Last updated: 2026-08-27 · deployed release: 94d624d

## Current state summary

Ledger is a React/Flask Annual Report benchmark with matched four-parser arms: Strategy 1 disables OCR; Strategy 2 enables compulsory or page-adaptive OCR and records page-level provenance. pdf-inspector-routed pages in Strategy 2 and Strategy 3 use local RapidOCR PP-OCRv6 ONNX at 200 DPI. Strategy 3 ranks unified complete pages deterministically and sends three to five pages to semantic mapping, with one bounded evidence-retry call when required. That retry receives a compact baseline for permitted rows and exact failed-identity discrepancies; non-permitted rows remain immutable and replacements require deterministic arithmetic, PPE-measurement, or source-citation improvement without reconciliation regression. Confidence below 0.80 prioritizes review but does not hide returned values from arithmetic or exact scoring. The retained benchmark contains 75 gold-backed documents across 34 companies. Filtering the fresh no-reuse validation to this owner-approved cohort yields 1,099/1,099 exact scored rows and 75/75 exact documents: 100% row-micro and 100% document-macro accuracy. The cohort removal is not yet deployed.

The corpus keeps one atomic company/year PDF, uses cross-process manifest locking and a 12.5-second Firecrawl gate, and persists corpus/extraction jobs across navigation and refresh. Assignment gold is admitted only for the exact supplied 3M FY2022 PDF SHA-256; company/year labels alone cannot inherit it. Discovery follows a bounded set of same-domain official annual/securities-report library links, rejects arbitrary search results when no official domain is known, and verifies annual-document plus company identity from the PDF itself. Downloaded candidates must screen `ok` before replacing a canonical report, and Unicode company names remain distinct instead of collapsing to `Unknown_Company`. Firecrawl is discovery-only. Candidate review is extracted-first: one configured-LLM semantic-mapping pass produces a provisional table, the UI shows one rendered A4 page by default with an explicit searchable-full-PDF mode beside 27 prefilled rows, reviewers correct discrepancies, then Save & Approve. Legacy Firecrawl candidates are replaced on review; failures show Retry instead of blank manual inputs.

Anonymous browser workspace IDs isolate staged files, jobs, run history and run deletion between ordinary public visitors without pretending to be authentication. The public dashboard uses a separate exact-source benchmark feed and reports three equal-weight experiment means—no OCR, OCR enabled and intelligent scanning—without exposing private visitor history. The localized corpus library groups the manifest-backed fiscal years below each of the 34 retained companies; stale research prospects are no longer mixed into the runtime library. Values default to a USD display conversion while extraction, gold and exact scoring remain in the filing currency. Vercel serves the bilingual responsive client; Tokyo EC2/Caddy/Gunicorn serves the API and persistent encrypted-EBS artifacts. Provider, Firecrawl, Upstash and SES credentials remain backend-only.
